Country flag PNGs downloaded from https://flagcdn.com/w80/{code}.png (Flagpedia, based on Wikimedia Commons flag vectors).

Source and download documentation: https://flagpedia.net/download/api

These assets are bundled locally; the app never contacts the flag CDN. The Catalan flag is drawn in code. Country flags are visual hints alongside the full native language names, not identifiers for every place where the language is spoken.
